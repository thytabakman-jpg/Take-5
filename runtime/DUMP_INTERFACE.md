# Take-5 Experimental Dump Interface

Status NONPRODUCTION

Place a corpus in a directory and optionally add a take5.json manifest.

Directed manifest fields are id, job, and protected constraints.

A manifest with id only is zero-request mode. The corpus supplies the evidence and the runner must not invent an external substantive goal.

Each run produces a typed inventory, discovered work frontier, capability route, execution ledger, verification receipt, and persistent event record.

The controller and worker remain separate. The reference worker is deterministic and exists to test the foundation interfaces. A general semantic-worker adapter remains a separate implementation coordinate.
