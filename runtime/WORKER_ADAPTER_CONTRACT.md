# Semantic Worker Adapter Contract 001

Input includes Frozen Target, typed state, selected capability or package, corpus references, authority grant, and continuation basis.

Output includes result, evidence and provenance, execution-truth state, target effect, OPEN or blockers, proposed state delta, verification hooks, and continuation signal.

The controller selects and reselects work. The worker performs substantive capability work. The worker cannot expand its authority or promote its own result.

The current deterministic reference worker tests interfaces only. A general reasoning worker remains an OPEN adapter implementation.
