## G Governing goal

X
Grade 5–6 learner who already asks ordinary questions.

T
Move from treating a question as merely something said or written toward understanding a question as a deliberately structured missing piece that can be made answerable.

I
A possible four-page Sukkos learning experience.

Sigma
On a new case, the learner can turn an undifferentiated "I do not know" into a question that identifies what is missing and what would count as closing the gap.

## C Core object

Candidate model:

question = structured known state + deliberately identified gap + closure condition.

This is an alternative to the accepted Project 1 partition/classification route.

## K Context binding

Candidate Sukkos connection:

a sukkah may offer an embodied case in which a structure can be fit for its role without becoming an ordinary sealed permanent house.

The useful connection may be deliberate bounded incompleteness.

This is not yet accepted.
The exact structural correspondence remains a blocking open question.

## M Mechanism

Learners distinguish:

random missing information
from
a deliberately shaped information gap.

They then practice shaping a gap so an answer can close it.

## R Route skeleton

missing
-> structured missing
-> question
-> possible Sukkos embodiment
-> independent transfer.

## E Observable evidence

Given something unknown, the learner can state:

what is already fixed,
what exact information is missing,
what answer would close the gap.
