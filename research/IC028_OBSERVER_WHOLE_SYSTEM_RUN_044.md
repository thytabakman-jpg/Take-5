## 1 Independent observations retained before reconciliation

### SYSTEM
Take-5 contains a stronger explicit legality/control architecture than the prior Reaserch system, but the executable path is fragmented across many small runtime modules and repository artifacts. The system has learned how to describe activation, currentness, work, representation feedback, evidence, reentry and challenge, yet no single fast configured program demonstrably compiles all of them into the ordinary user path.

### SUBSYSTEM
The strongest subsystems are individually coherent:
currentness; activation/evidence; typed Work; RCDL; scope/mode geometry; historical challengers; tool maturity; configured runs.
Their interfaces are the weak point. Many are callable modules but not mandatory transitions in one controller episode.

### COMPONENT
The codebase contains numerous scaffolds whose names imply more operational power than their implementation currently provides. Examples:
autonomous_observer observes generic records only;
mo_mt generates challenge objects but does not itself execute the challenged tools;
capability_router selects by tags but does not execute selected programs;
controller_lease controls selection authority but not persistent scheduling.
This is a realization gap, not a semantic defect.

### INTERFACE
The chat interface remains the de facto scheduler. User messages frequently supply the next transition. Therefore Jane is not yet the persistent endogenous controller the architecture describes.

### BOUNDARY / DECOMPOSITION
The current decomposition over-separates governance from action. Currentness, evidence, authority, activation, routing, execution, admission, persistence and reentry are correct distinctions, but repeated remote/reconstruction crossings make the hot path expensive.

### CROSS-LAYER
The largest cross-layer loss is:
semantic discovery -> executable work -> affected-consumer propagation.
A result can be represented correctly without causing all dependent executable consequences.

## 2 Mode shake

EXPAND:
The object universe includes historical ICs, C01-C49, named composites, labs, projects, issue ledger, maps and user-observed behaviors. Migration completeness cannot be judged from Take-5 files alone.

CONTRACT:
The many symptoms compress to one operational residual:
the system lacks a compiled end-to-end continuation engine.

INWARD:
The core missing relation is not another semantic primitive. It is mandatory composition of existing primitives.

OUTWARD:
The same defect explains tool non-use, migration omissions, backlog persistence, folder-refinery incompleteness, booklet-generator incompleteness and repeated prompting.

ISOLATE:
Remove chat/user prompting as a scheduler. The system stalls at several frontiers. Therefore conversational prompting is currently load-bearing.

COUPLE:
When IC-028 execution truth, Jane Work, RCDL, BindingTopology affected-cone direction and controller lease are coupled, a plausible missing engine appears:
Event -> Work -> Bind -> Execute -> Admit -> PropagateAffectedCone -> Persist -> Reenter.

## 4 Tool-use audit

The old All-Tools Campaign stated that use means:
selected -> bound -> executed -> result consumed -> ledger updated -> frontier reassessed.

Current system does not yet demonstrate that invariant for all C01-C49.
Therefore 'we have all tools' is true at registry/semantic availability level but not proven at configured native-use level.

Important observer result:
the system has confused CAPABILITY COMPLETENESS with PROGRAM COMPLETENESS.

C01-C49 can all exist while the program that composes them into live research behavior remains incomplete.

## 5 Why the old system felt alive

The useful property was not simply fewer files or weaker rigor.
It had a lower-friction representation/action loop:
broad observation -> connection generation -> recursive tool application -> artifact/state change.

Take-5 improved correctness controls but moved many of those behaviors behind explicit modules, gates and reconstruction steps. The old emergent loop was decomposed faster than it was recompiled.
