# GDOS First Experimental Tranche Results 001

Date: 2026-09-24
Status: SEMANTIC EXPERIMENT / FIRST TRANCHE
Authority: research only
Execution truth: semantic GDOS study over frozen capability specifications; does not imply runtime execution of unbound C20-C48 or CAP programs.

## Frozen method

For each object:
1 freeze exact current specification;
2 suppress improvement, repair, confirmation, and completion pressure;
3 ask only what structure becomes visible under the observer;
4 preserve observations independently;
5 reconcile only after the observation set is frozen.

## Behavior-sweep reconciliation

First robust pattern:

GDOS gain is positively associated with native intervention pressure.

High-gain families:
STRENGTHEN, GENERATE, ROUTE/REENTRY, CLOSURE, REPRESENTATION/INTERACTION.

Lower-gain but still protective families:
TYPING, PROVENANCE, AUTHORITY GUARDS.

This falsifies the crude hypothesis that GDOS simply makes every capability better.

## B. Tool-target sweep C01-C49

ORIENT C01-C06:
mostly low-to-moderate incremental gain. C05 Target Job Freeze is a prerequisite rather than a major beneficiary. C03 Currentness and C02 identity are already structurally observational.

MAP C07-C13,C49:
high overall gain. C07 hidden dependency, C08 plural spines, C10 representation attack, C12 invariant localization, and C49 corpus navigation all expose material structure that goal-conditioned search prunes.

ATTACK C14-C19:
high gain, especially C17 diagnosis, C18 root-cause escalation, C19 recursive discovery. C14 hostile review gains less when its target defect class is already frozen.

GENERATE C20-C23:
very high predicted semantic gain. These tools are presently runtime-unbound, so this is a semantic observation result only. Rival and successor generation are especially sensitive to target-conditioned narrowing.

IMPROVE C24-C35,C48:
highest overall GDOS-control residual. The family is almost definitionally optimization-loaded. C24 repair, C26 system architecture improvement, C30 boundary redesign, C32 routing, C33 strict gain, and C48 raise-ceiling all benefit from an observation pass before intervention.

TRANSFER C36-C43:
mixed. C37 provenance and C38 license are relatively goal-resistant. C39 target-effect, C40 coverage, C41 rescue, and C43 consequence handoff are more vulnerable to target usefulness contaminating source/bridge analysis.

VALIDATE C44-C47:
moderate/high. C47 closure shows very strong benefit. C45 holdout gains mainly through information-barrier protection rather than goal decoupling alone.

## C. Anchor matrix first-pass results

### B07 Differentiate -> B10 Strengthen
GDOS exposes distinctions that strengthening would normally ignore because they do not define an obvious successor dimension.
Reverse B10 -> B07 is narrower: strengthen frames differentiation around gain coordinates.
ASYMMETRIC.

### B08 Relate -> B13 Interaction Residual
Strong complementarity. Relation supplies candidate edges; interaction residual tests whether the joint structure exceeds them.
Reverse direction generates candidate relations from unexplained residuals.
Both directions material; non-equivalent.

### B09 Reconstruct -> B38 Noncommutation
Reconstruction identifies which behavior must survive across order variants.
Reverse direction identifies when one reconstruction is order-contingent.
Strong bidirectional residual.

### B10 Strengthen -> B23 Verify
Normal order risks verification target selection around the favored successor.
Independent GDOS observation followed by verification produces a broader protected set.
Order-sensitive.

### B13 Interaction Residual -> Improvement Core
Material discovery: IC's behavior cannot be reconstructed as merely the union of its tools. Routing, timing, admission, and reentry create controller-level residuals.

### B16 Route -> Improvement Core
Material discovery: IC and routing are deeply coupled but not identical. IC contains problem generation, interpretation, integration, and reentry beyond route selection.

### B20 Diagnose -> Improvement Core
Confirms two distinct IC failure classes:
1 semantic/controller reasoning failure;
2 binding/execution failure.
The earlier tool-use problem was primarily class 2 after behavior-first compression.

### B23 Verify -> Kernel
Kernel increasingly looks less like a computational component and more like a set of transition predicates whose existence is demonstrated by bypass/regression tests.

### B38 Noncommutation -> GDOS
Major result:
Observe -> GoalFilter and GoalFilter -> Observe are noncommutative.
Also:
ObserveAllFrozen -> Reconcile and Observe -> Mutate -> Observe are noncommutative.

### B40 Completion -> GDOS
GDOS itself needs a typed stopping claim. "Nothing else interesting appeared" is not global completeness. Its natural stop is basis-relative observation saturation.

### Improvement Core -> Kernel under GDOS
IC supplies adaptive continuation; Kernel constrains legal continuation. The relation is not parent/child in a simple software-layer sense.

### Kernel -> Improvement Core observation
Kernel invariants explain what IC is forbidden to do, not what IC positively does. This is evidence against defining IC as merely a Kernel executor.

## D. Initial matched GDOS/control contrasts

Across one representative from each major family, three recurring GDOS-only classes appeared:

1. non-instrumental dependencies:
facts structurally relevant to the object but useless to the immediate solution;

2. alternative decompositions:
structures discarded in control because one decomposition already supported action;

3. control-path observations:
facts about routing, stopping, authority, or representation that are hidden when attention is fixed on object-level improvement.

Control-only findings also exist:
goal-directed mode is better at immediately identifying actionable interventions and can suppress large amounts of nonmaterial structure.

Therefore GDOS is not a replacement for normal IC. Best observed architecture remains:
GDOS -> reconcile -> goal-conditioned IC.

## E. Component-ablation early result

The strongest effect is not goal decoupling alone.

Observed qualitative ordering on high-yield cases:

goal decoupling only < goal decoupling + frozen target < goal decoupling + independence + frozen target < goal decoupling + independence + deferred reconciliation + frozen target.

This is provisional semantic evidence, not yet a randomized runtime result.

The interaction term Independence x DeferredReconciliation appears especially important because immediate integration changes the target seen by later observers.
