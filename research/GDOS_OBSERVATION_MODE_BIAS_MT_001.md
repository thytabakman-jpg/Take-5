# GDOS Observation of Mode/Bias MT Results 001

Date: 2026-09-24
Status: OBSERVATION-ONLY RESULT
Authority: research only

Frozen object:
MT_GDOS_COUNTER_REGIME_IC_SKILL_USE_001 plus MT_BIAS_MODE_CAPABILITY_USE_001.

No improvement or architecture mutation was permitted during observation.

## Independent observations

1. Broad versus focused is not one continuum.
Two orthogonal axes are visible:
- breadth: expand/contract;
- directionality: observe/act.

This yields four controller quadrants rather than two modes.

2. The proposed FOCUS regime is not the inverse of GDOS.
GDOS reduces premature outcome selection.
FOCUS increases scope selection around a frozen discriminating question.
Both can reduce different biases.

3. Outcome selection and scope selection must be separated.
Suppressing outcome selection can be useful while increasing scope selection.

4. Specialized skill invocation appears to live in CONTRACT+ACT.
GDOS lives in EXPAND+OBSERVE.
Therefore a controller optimized for GDOS can still fail to use specialized skills.

5. IC's historical "tool avoidance" is consistent with a stable global-controller preference for retaining transformation control.
The system can select a skill, understand it, and even bind it, yet still fail to delegate the local transformation.

6. This creates a fourth execution-truth distinction:
considered != selected != bound != delegated != executed != reintegrated.

7. Real delegation requires output autonomy.
A skill has not meaningfully been used when its result is constrained to match what the global controller would have produced anyway.

8. The bias problem is larger than confirmation bias.
The current system is exposed to selection, anchoring, framing, retrieval/availability, closure, formalism, architecture, novelty, survivorship, authority, order, user-pressure, semantic-simulation, and reintegration biases.

9. Some biases are endogenous to modes:
EXPAND risks over-inclusion and equal-attention distortion.
CONTRACT risks omitted-variable and anchoring effects.
ACT risks outcome-driven evidence selection.
OBSERVE risks endless/non-instrumental accumulation.

10. Therefore no mode is globally privileged.
Mode selection itself requires challenge and can remain OPEN.

11. A cheap mode preflight may be necessary:
identify whether the immediate failure risk is premature pruning, irrelevant breadth, action paralysis, or uncontrolled intervention.
But this preflight cannot fully decide the task type without circularity.

12. Behavior interaction requires typed composition.
The same pair can ADD in one mode, GATE in another, and INHIBIT in a third.
This means "combine tools" is underspecified until interaction type, order, and mode are fixed.

13. Reconciliation is also mode-sensitive.
Broad reconciliation preserves plural structure.
Focused reconciliation resolves one contradiction or discriminating coordinate.
Action reconciliation selects what becomes an intervention.
Thus reconciliation is likely a family, not one scalar operation.

14. Bias checking itself can be biased.
A fixed checklist can over-detect familiar biases and miss new nuisance coordinates.
A robust bias audit needs both a known-bias basis and a residual search for unexplained task-irrelevant sensitivity.

15. BPA's irreducible contribution, if any, is not "knowing bias names."
It is systematic nuisance perturbation under frozen protected semantics.

16. The most powerful general form is:
freeze what must remain invariant;
vary what is claimed irrelevant;
observe whether result changes.

This pattern unifies bias testing, representation attack, robustness testing, order testing, and some holdout logic while keeping their jobs distinct.

17. GDOS may be viewed as one large perturbation:
remove optimization-goal cues while preserving target identity.
FOCUS can be viewed as another:
remove irrelevant scope while preserving discriminating semantics.

18. The regime study therefore becomes a perturbation experiment on the controller itself.

19. Kernel implications remain mostly negative/protective:
preserve declared invariants across perturbation;
record exact mode and observation basis;
forbid false execution/delegation claims;
do not decide which mode is best.

20. The strongest new connection to IC tool use is delegation bias:
global synthesis has a structural advantage because it is always available inside IC, while external/specialized execution requires extra transition steps.
This creates a default-path bias even without any explicit preference.

## Reconciled result

Current candidate architecture is not merely:
GDOS -> reconcile -> IC.

It is closer to:

MODE PREFLIGHT
-> EXPAND+OBSERVE when premature pruning risk dominates
-> RECONCILE
-> CONTRACT+OBSERVE when exact resolution is needed
-> CONTRACT+ACT for specialized delegated capability execution
-> EXPAND+ACT only when broad system intervention is licensed
-> VERIFY
-> perturbation/bias check where result sensitivity warrants it
-> REENTER.

Paths may skip modes.

The unresolved research question is not which mode is best.
It is how to detect, with minimal circularity, which information-loss/failure risk warrants which mode.
