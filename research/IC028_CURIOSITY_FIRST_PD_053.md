## 1 Ordering correction

Old:
SelectQuestion -> RootTranslate -> PDEnrich -> Expand36.

New:
CuriosityGenerate -> PDQuestion -> QuestionIdentityFreeze -> RootTranslate -> Expand36 -> Probe/Execute -> Reconcile -> Reenter.

Reason:
RootTranslate requires a stable enough question referent.
PD can reveal that the raw question conflates targets, answer spaces, levels, presuppositions, or selectors.
Therefore mathematicalizing before PD can precisely formalize the wrong question.

Recursive exception:
after mathematicalization exposes new distinctions, PD reenters.
So PD is both pre-formalization question refinement and post-formalization audit.

Across admissible theoretical and measurement frameworks, what object(s) are called emotion, which properties are constitutive versus causal/correlational/measurement indicators, and is there a framework-independent extension or only framework-indexed extensions?
