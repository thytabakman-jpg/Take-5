## Discovery

The six-scope ontology is no longer Architecture-only.

SCOPE = {SYSTEM, SUBSYSTEM, COMPONENT, INTERFACE, BOUNDARY_DECOMPOSITION, CROSS_LAYER}.

It already appears as a shared coordinate in:
Architecture Analysis
Diagnosis/Root Cause
MTA
and ordered scope handoffs.

The six are not six arbitrary zoom levels.

They factor into three species:
Containment = {SYSTEM,SUBSYSTEM,COMPONENT}
Relation = {INTERFACE,BOUNDARY_DECOMPOSITION}
Transport = {CROSS_LAYER}.

Boundary is an identity/decomposition transformer, not containment.
Interface is a relational object.
Cross-Layer is transport.

Therefore the correct research question is not "force every tool to have six."
It is:
for each tool family, is SCOPE result-sensitive, and if so which projections/handoffs are admissible?

## Root cause of current foundation weakness by six scopes

SYSTEM
The foundation was optimized around semantic roles/controller/runtime closure before fully representing scope-sensitive discovery and causation.

SUBSYSTEM
Tool families evolved unevenly. Some had scope semantics, others only local configured-run wrappers.

COMPONENT
Individual tools could be mathematically strong while lacking an explicit scope coordinate and scope-relative closure.

INTERFACE
Typed handoffs existed for activation and capability execution, but scope-to-scope handoffs were not a universal governing interface.

BOUNDARY_DECOMPOSITION
The architecture repeatedly treated decomposition choices as fixed background rather than objects that can change identity, responsibility, candidate generation, and causal attribution.

CROSS_LAYER
Semantic discoveries in Reaserch did not reliably invalidate/rebase Take-5 foundation claims. PR129/RCDL exposed the same transport weakness for representations and candidate universes.

Root generator:
SCOPE ONTOLOGY WAS DISCOVERED LOCALLY BUT NOT PROMOTED TO A SHARED RESULT-SENSITIVE COORDINATE OF THE FOUNDATION.

## Six-scope Architecture on the architecture itself

SYSTEM
The whole research system is controlled representation-coupled endogenous discovery under authority/evidence/closure constraints.

SUBSYSTEM

COMPONENT

INTERFACE
Every material handoff must type semantic identity, authority, evidence, OPEN/BLOCKED, order/timing and consumer obligations.

BOUNDARY_DECOMPOSITION

CROSS_LAYER
Semantic -> architecture -> controller -> runtime -> evidence -> persistence -> authority transport must preserve identity and currentness. A pass at one layer cannot certify another without a bridge.

## Is six fundamental?

OPEN.

Evidence for:

Evidence against premature canonization:
some tools may be scope-invariant;
some domains may need a different coordinate;
six may be a useful basis for architecture-like objects rather than a universal minimal ontology;
minimality/independence/completeness have not been proven.

attempt reduction/merger;
search for seventh irreducible scope;

test whether scope distinctions change protected results, OPEN state, attribution, or legal continuation.
