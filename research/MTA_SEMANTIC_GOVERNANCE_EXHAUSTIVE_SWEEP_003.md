## O2 Semantic delta

Current representation Delta_H(S,r) is under-typed.

A delta is not simply textual difference and not necessarily an object.

Stronger candidate:
Delta_H^J(s,s') = equivalence class of result-sensitive semantic differences between states relative to job J and continuation basis H.

But this creates a circularity risk: to compute delta between proposed and admitted state, one must already represent the proposed effect.

Better architecture separates Proposal p from admitted state:
Eff(p,s) = candidate effect description.
Delta_{J,H}(s,p) = semantic difference induced by the proposed effect modulo continuation-relevant equivalence.

OPEN:
universal semantic equivalence is not available.

## O5 Admission dispositions

{ADMIT,REJECT,MERGE,RIVAL,OPEN,BLOCKED} mixes two axes.

ADMIT/REJECT are effect decisions.
MERGE is an identity/reconstruction relation.
RIVAL is a relation among candidate claims/models.
OPEN/BLOCKED are epistemic/execution statuses.

Single enum creates typing loss.

Factor candidate:
Decision in {ALLOW,DENY,DEFER}
IdentityRel in {NOVEL,MERGE,EQUIVALENT,SUPERSEDES,...}
Epistemic in {SUPPORTED,OPEN,CONFLICT,...}
Execution in {BOUND,UNBOUND,BLOCKED,...}

Exact product schema OPEN, but typed axes are required.

## O6 Certified legal-transition relation

Previous formula:
LEGAL(S->S') iff exists delta,c [Delta=delta and Licenses(c,delta,S,S')].

MTA finds delta is eliminable from the minimal relation if certificate already identifies the proposed effect.

Smaller candidate:

LEGAL_K(s,p,c)
iff
WellTyped_K(p)
and Adequate_K(c,p,s)
and Authorized_K(c,p,s)
and Preserves_K(c,p,s).

Then transition:
s' in U_K(s,p,c)
only if LEGAL_K(s,p,c).

This is stronger because it separates:
proposal p;
certificate c;
legality judgment;
update U;
resulting state s'.

It also reconnects cleanly to the existing eight-role system where K constrains U.
