# PD Audit — CORE 001

Date: 2026-09-24
Status: CANDIDATE DEFINITION / OPEN UNDER EXTERNAL COMPARISON
Target: foundation-before-migration

## Problem

Historical artifacts use core in at least three materially different senses:
1. core operator — a primitive substantive job transform;
2. Improvement Core / ICC — a controller lineage;
3. system core/foundation — the smallest load-bearing machinery needed to reconstruct protected system behavior.

These are not extensionally identical.

## PD result

For the current foundation task, define SYSTEM CORE relative to protected behavior B and admitted contexts K as a minimal reconstructive basis C* such that the configured system built from C* preserves B over K, and no proper admissible reduction of C* preserves the same behavior.

Candidate criterion:
Core_B,K(C) iff Reconstructs_B,K(C) AND Minimal_B,K(C).

This is role-neutral. A core component can be a contract, state coordinate, transform, generator, control, router, update law, interface, or other role if ablation proves it irreducible for protected behavior.

Therefore:
CORE != list of operator families.
CORE != ICC.
CORE != KERNEL.
CORE != all useful capabilities.
CORE != implementation package.

A CORE OPERATOR is one member/family inside the system core only when its substantive result topology is irreducible under the configured job.

## Result-sensitive tests

A candidate x belongs in system core only if:
1. removing/factoring x loses a protected result/continuation class;
2. the loss cannot be reconstructed by remaining components plus admissible specialization/composition;
3. the distinction survives representation change;
4. its role and interfaces are typed;
5. OPEN/incomparability are not collapsed to manufacture minimality.

## Current implication

The existing nine-family core-operator basis is evidence about O, not a complete definition of SYSTEM CORE.

The eight-role architecture is a candidate decomposition of the system core/foundation, but role survival and component minimality remain separate questions.

## OPEN

Whether the system core is best represented as a minimal set of roles, a minimal set of behavioral factors, or a typed generating basis over roles is not frozen yet. External comparison and cross-role ablation must discriminate.
