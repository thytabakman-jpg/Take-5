## Invocation law

Run(IC-n,X) means:
1 resolve the local canonical reconstruction;
2 freeze X and the controller's declared evaluation/completion basis;
3 execute the controller semantics using currently available executable bindings;
4 record semantic-only versus implementation-executed states;
5 preserve OPEN/BLOCKED/CONFLICT;
6 return admitted results to Jane/Take-5 as challenger evidence;
7 do not self-promote historical authority.

Historical source retrieval is provenance verification, not the normal invocation path.

## Migration invariant

Reusable historical capability h is migration-complete only when:

LocalDiscoverable(h)
AND CanonicallyReconstructible(h)
AND DependenciesResolved(h)
AND InvocationSemanticsKnown(h)
AND AuthorityDispositionKnown(h).

An archive pointer alone is insufficient.

## Scope

This library is intentionally compact. It does not copy the whole historical repository.
It copies canonical callable controller specifications plus the minimum reconstruction surfaces required for invocation.
Raw provenance remains in Reaserch.
