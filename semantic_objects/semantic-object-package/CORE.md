# semantic object package

Object ID: OBJECT:SEMANTIC_PACKAGE
Type: PERSISTENT_SEMANTIC_CONTAINER
Status: DEFINED

## Current definition

A durable non-overwriting representation for one load-bearing semantic object, consisting of a current core projection, manifest, 36 directed scope-transition pages, and append-only evidence history.

## Known

- package existence does not imply semantic closure
- unknown transition cells are explicit OPEN
- evidence is append-only
- current summary can change only with lineage

## OPEN coordinates

- optimal additional page families beyond the current core plus 36 surface
- historical backfill completion

## Dependencies

- six-scope ontology
- artifact reality
- currentness
- semantic lifecycle

## Protected uses

- prevent semantic drift
- preserve unresolved coordinates
- support tool/object currentness and reconstruction

## Lifecycle rule

New evidence is additive. Unresolved coordinates remain visible until explicitly resolved with provenance.
