# black box

Object ID: TERM:BLACK_BOX
Type: SEMANTIC_STATUS_CONCEPT
Status: DEFINED

## Current definition

A black box is a load-bearing semantic object whose operational role or constraints are known enough to use conditionally while at least one semantic coordinate required for stronger claims remains unresolved. The unresolved state must remain explicit and durable.

## Known

- BLACK_BOX_OPEN is legal
- silent treatment as solved is prohibited
- open coordinates and affected uses must be recorded

## OPEN coordinates

- instance-specific unresolved coordinates are carried by each black-box object, not by this definition

## Dependencies

- semantic preflight
- artifact reality
- result sensitivity

## Protected uses

- permit unresolved primitives without semantic drift
- block stronger claims that require unresolved semantics

## Lifecycle rule

New evidence is additive. A later current summary may supersede an earlier summary only with explicit lineage. Unresolved coordinates are never removed merely to simplify the page.
