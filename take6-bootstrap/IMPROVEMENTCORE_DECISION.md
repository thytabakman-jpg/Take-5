# ImprovementCore Greenfield Decision

Date: 2026-09-26

Status: GREENFIELD SUCCESSOR LICENSED / PROMOTION NOT LICENSED

## Evidence supplied

The prior full-system regression response, the Reaserch permanence gate, current Reaserch v5 changes, and current Take-5 repository architecture were treated as evidence rather than as a fixed repair plan.

## Observed problem

The historical failure is not one missing wrapper.

The recurring class is authority fragmentation:

- exact evidence lives in one place;
- current semantic identity is expressed elsewhere;
- runtime binding lives elsewhere;
- human summaries become de facto authority;
- multiple CURRENT pointers and registries require synchronized edits;
- compression can preserve names while dropping behavior;
- cross-project effects can remain local;
- a later chat may recover the label without recovering the exact executable object.

Take-5 has strong defenses, including protected-transition integrity, bound ZIP intake, durable knowledge capture, recovery manifests, exact configured-tool execution, and a legacy restoration target.

Those defenses materially reduce regression.

They do not remove the architectural pressure created by many independently maintained projections.

## ImprovementCore decision

Do not continue solving the universal problem by adding another peer registry, another CURRENT file, another manual synchronization rule, or another wrapper around the same mutable projection architecture.

Build Take-6 as a greenfield successor whose source of truth is immutable evidence plus immutable events.

Compile current state.

Generate views.

Execute exact capsules.

## Why the split matters

The new architecture moves persistence outside ImprovementCore.

ImprovementCore can therefore regain legacy flexibility.

It can change its inquiry policy, routing, recursion, tool choice, or controller structure without becoming the sole carrier of memory or currentness.

A controller regression cannot delete historical evidence.

A compressed view cannot redefine current truth.

A runtime rewrite cannot silently replace semantic identity.

A project-local discovery cannot count as propagated until the compiler closes the affected cone.

## External blocker

The available GitHub connector in this session does not expose repository creation.

That boundary does not justify folding Take-6 back into Take-5.
