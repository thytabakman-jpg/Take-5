# Compile Prompt

## Objective

Reduce unnecessary independent files while improving information organisation, coherence and accessibility without compromising information, provenance, structural integrity or functionality.

Freeze the authorised scope and Git revisions. Retrieve and follow [Compile Mathematics](https://github.com/thytabakman-jpg/Take-5/blob/main/Compile%20Mathematics.md) and its [Execution contract](https://github.com/thytabakman-jpg/Take-5/blob/main/Compile%20Mathematics.md#execution-contract); verify the three executables and run the [test suite](https://github.com/thytabakman-jpg/Take-5/blob/main/tests/test_compile.mjs) before computational work. Execute the following steps in order; complete each required result before advancing. Reuse outputs rather than repeating computations.

## 1. Discover

Execute [Decompiler — Discovery](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_decompiler.mjs) (mode: `discover`). Identify and group files that merit compilation; record the evidence and scope limits. Defer final survivor and retirement decisions.

## 2. Consolidate

Execute [Decompiler — Consolidation](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_decompiler.mjs) (mode: `decompose`). Combine each group's complete admitted information, including material historical revisions, into one lossless temporary working document. Preserve every original occurrence and source identity.

## 3. Decompile

Use the [Decompiler — Decomposition](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_decompiler.mjs) output (`units`). Separate information into independently identifiable components; retain every source location, context and relationship. Refine structural units into meaningful semantic components where necessary.

## 4. Layer

Use [Decompiler — Layering](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_decompiler.mjs) (`working.layered`, `layerByUnit`). Organise every information component by type, establish additional layers where useful, and place otherwise unclassified but understood material in Other. Review unresolved classifications separately; account for every unit.

## 5. Deduplicate

Use [Decompiler — Comparison](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_decompiler.mjs) (`exactGroups`, `similar`, `layerComparisons`). Eliminate redundancy within layers without losing distinct meanings, qualifications, context or evidence. Record the surviving representation of every removed unit; similarity alone is not equivalence.

## 6. Synthesize

Integrate complementary information within and across layers. Produce coherent representations while preserving distinct positions, evidence, qualifications and historical lineage.

## 7. Architect

Reconstruct the synthesised information according to its distinct responsibilities, ownership and relationships. Use [Architecture](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/architecture_analysis.py) where applicable; establish a coherent architecture with justified component separation.

## 8. Assign and adjudicate

Establish final information homes, file architecture and section/anchor mappings. Compare every proposed transformation against the actual original state:

- **GO:** Improve at least one relevant dimension without worsening any other; implement after verification.
- **NO-GO:** No meaningful gain, or an identified regression cannot be resolved; retain the better existing arrangement.
- **TWEAK:** Improve the proposed arrangement to preserve the advantages of both states wherever a regression or missed gain exists; reassess.

Assess informational, historical, mathematical, architectural, navigational and functional consequences. Missing evidence blocks clearance; resolve it where possible. Freeze final destinations and retirement decisions before transforming references.

## 9. Repair dependencies

Execute [Dependency Repair](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_dependencies.mjs) in `prepare` and then `audit` modes using frozen original source locations and final destinations. Integrate transformed references into reconstructed content and reconcile affected inventories, registries and consumers. Resolve all affected necessary dependencies.

## 10. Verify

Execute [Compilation Verifier](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_verify.mjs) with the actual decomposition, independent dependency audit and preservation evidence. Require verified information conservation, durable provenance, structural and functional integrity, and clearance for every authorised retirement before publication.

## 11. Implement

Publish all cleared and authorised changes through guarded Git commits; physically eliminate every cleared redundant file. Preserve concurrent changes and the provenance record. Do not substitute redirect placeholders or recommendations for actual retirement.

## 12. Confirm

Execute [Compilation Verifier — Publication Verification](https://github.com/thytabakman-jpg/Take-5/blob/main/runtime/compile_verify.mjs) against independently retrieved committed content. Confirm file elimination, information preservation, provenance, dependency integrity and applicable functional tests; report actual changes and remaining blockers.
