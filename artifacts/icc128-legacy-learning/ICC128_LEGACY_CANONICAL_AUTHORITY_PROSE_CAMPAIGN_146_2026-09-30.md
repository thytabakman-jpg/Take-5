## Learning 1 — upgraded GOAL receipt requirement changes truthful execution reporting

The ceiling-raised GOAL identity now requires a robust-MT execution receipt before
a configured GOAL run can be claimed.

Campaign consequence:
- MT must be explicit in the paragraph and section spine;

  after the fact;
- the receipt requirement materially reduces tool-downgrade ambiguity.

Learning classification: durable execution-discipline learning.

## Learning 2 — PROSE ordered anchors are useful above sentence scale

The new PROSE ORDERED_ANCHORS behavior was designed as an opt-in order lock.
This campaign showed that the same protected primitive is useful at two scales:

1. paragraph phase — protect local claim/sentence anchors while revising prose;
2. section phase — protect paragraph order while allowing additive section
   handoff improvements.

The section pass found nine strict gains that did not require moving or deleting
any paragraph. This is evidence that order protection and prose improvement are
compatible rather than competing objectives.

Learning classification: durable capability-composition learning.

## Learning 3 — intentional bloat is a protected state, not absence of editing

RTC can improve an intentionally overfull draft without converting the campaign
into compression.

In this run:
- no cut pass was authorized;
- 55 paragraph objects remained;
- 23 sections remained;
- paragraph/section order remained fixed;
- the full configured campaign increased the manuscript by 166 words relative to
  the prior simple-PROSE successor.

Therefore “keep it bloated” should be represented as a protected constraint
against deletion/compression-for-length, not as a ban on local clarification,
full-force claim restoration, or additive handoffs.

Learning classification: durable project-policy representation learning.

## Learning 4 — paragraph closure does not eliminate section-level work

After all paragraphs reached local relative closure, the section pass still found
nine result-relevant reader-flow gains.

This establishes a scale distinction:

[
ParagraphClose 
Rightarrow SectionClose.
]

Local prose correctness does not guarantee that section entry/exit relations are
maximally clear.

Learning classification: durable multi-scale closure learning.

## Learning 5 — section mutation requires preservation re-entry below the section

Section-level changes can mutate the terminal paragraph of a section after that
paragraph previously closed.

Therefore a section-level admitted mutation must carry:
- paragraph protected-claim preservation;
- PROSE acceptance;
- RTC re-entry;
- no-cut/bloat preservation.

A “paragraph phase complete” receipt is historical evidence, not a permanent
exemption from later lower-scale verification.

Learning classification: durable re-entry learning.
