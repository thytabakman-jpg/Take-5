order, with every factor crossing its full configured invocation profile and its registered
HF2 recurrence policy, then feed the combined result back through ProjectManager and
ImprovementCore until no unresolved local project-control consequence remains.

change the current mathematical object.

## Result interpretation

Tool execution status and substantive project status are separate.

A tool can execute successfully and return an OPEN finding. That OPEN finding is retained as
evidence rather than misreported as an execution failure.

The campaign distinguishes:

LOCAL_ACTION_REQUIRED
an admitted ProjectManager-controlled repair remains.

EXTERNAL_OPEN
a live result-sensitive coordinate remains outside current project authority or outside a
recovered current formal object.

CLOSED_RELATIVE
all local consequences are settled and any surviving external OPEN coordinate has an explicit
boundary and resume condition.

## Reentry

Pass 1 runs the complete 93-tool campaign against the current canonical project state.

Any admitted local delta is applied only through its owning project authority.

Pass 2 reruns the complete campaign against the changed project state.

The campaign ends only when:
all 93 configured factors executed;
all registered HF2 dispositions closed according to their own recurrence contract;
ToolConductor's exhaustive coverage sweep completed;
ImprovementCore consumed the combined result;
TRC closed local consequences;
no local project-control finding remains;
surviving external OPEN state is explicit and non-authorizing.
