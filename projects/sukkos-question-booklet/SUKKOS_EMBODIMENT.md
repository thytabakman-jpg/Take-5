# Sukkos Embodiment

Status: LOCKED_RELATIVE FOR CURRENT ROUTE
Date: 2026-09-27

## Holiday object

S'chach material.

## Core question

Can this material pass the three source checks used on this page?

## Source checks

1.
It grew from the ground.

2.
It is detached from the ground.

3.
It is not an object or material class that can receive ritual impurity.

The page supplies the ritual-impurity status for each classroom card rather than teaching the larger laws of tumah.

## Card set

Cut palm branch:
grown from ground yes.
detached yes.
receives tumah no.
Result:
passes today's three checks.

Live grapevine:
grown from ground yes.
detached no.
Result:
fails.

Metal bowl:
grown from ground no.
receives tumah yes.
Result:
fails.

Mystery leafy branch:
grown from ground yes.
receives tumah no.
detached status not given.
Result:
NEED MORE INFORMATION.

## Required learner question

Is the branch still attached to the ground?

This is the operational center of Page 3.

## Holiday surplus

The missing information is not arbitrary.

It changes classification under a real Sukkos source rule.

A generic sorting exercise lacks:
s'chach identity,
Jewish source authority,
holiday practice,
the legal relevance of attachment.

## Scope boundary

There are other laws of s'chach and sukkah construction.

Passing the page's three checks does not independently establish full halachic validity.

## Edible model disposition

An edible sukkah remains an optional post-booklet model activity.

It is not the core Page 3 evidence task and it is not represented as halachically valid s'chach.
