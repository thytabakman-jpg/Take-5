# Sukkos Embodiment

Status: OPEN / LEADING CANDIDATE RECORDED, NOT LOCKED

## Required job

Sukkos must embody the same question operation rather than merely supply an example.

## Leading candidate route

Use the sukkah as a bounded classification and design problem.

Core inquiry:

What makes something count as a sukkah?

The educational opportunity is not trivia about sukkah law. It is that an actual Sukkos object has identity conditions, constraints, edge cases, and inspectable evidence. A learner can only investigate it well by making the target and answer conditions explicit.

## Potential embodied move

Learners inspect or build a candidate sukkah under a small verified set of criteria.

Before acting, they improve the question.

Instead of only asking:
"Is this a sukkah?"

the booklet makes them specify what property is being tested, which facts or constraints matter, and what would count as resolving the case.

## Holiday surplus test

The route passes only when the actual Sukkos structure adds something a generic mystery-box or building activity cannot.
