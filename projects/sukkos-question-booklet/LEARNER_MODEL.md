# Learner Model

Status: WORKING

## Entry state

The learner can already ask ordinary questions.

The targeted gap is structural awareness.

A plausible entry state is:
"I know how to say a question, but I do not explicitly track what I am trying to find out, what information matters, or what would count as an answer."

## Exit state

The learner can inspect a question as an object.

Given a vague or weak question, the learner can improve it by making its information target and answer conditions clearer.

## Observable transformation

L0
→ encounter a question that succeeds or fails in a visible way
→ notice that questions have structure
→ learn a small reusable question model
→ use that model on a Sukkos-native case
→ use the model on a new case
→ L4.

## Evidence

A correct repeated slogan is not enough.

Evidence of transfer requires a new question or new case where the learner independently identifies missing structure and improves it.

## False positives

Prior knowledge.
Copying the booklet's wording.
Following a peer.
Guessing the teacher's desired answer.
Repeating a model without applying it.

## Emotional boundary

The final transfer can use a neutral external case. Personal disclosure remains optional.
