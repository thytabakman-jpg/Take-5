# Visual Master

Status: LOCKED_FOR_RENDER_CANDIDATE
Date: 2026-09-27

## Series identity

Four portrait pages.
Elegant illustrated educational style.
No photorealistic imagery.
No worksheet-grid aesthetic.
Small deer logo in the bottom corner of every page.
No portrait illustrations of rabbinic figures.
No blue-gray box system.

## Functional visual language

Target:
bullseye or focal-ring symbol.

Relevant facts:
filter or selected-card symbol.

Answer test:
gate or check symbol.

Every coordinate has both a symbol and a color identity so color is never the only cue.

Suggested palette family:
warm plum for Target,
ochre for Relevant facts,
leaf green for Answer test,
charcoal for body text,
warm cream page ground.

Exact color values remain renderer-free variables within this family.

## Page 1 composition

Top:

8 → 4 → 2 → 1.

make uncertainty reduction visible before defining anything.

## Density

One main visual per page.
One central operation per page.
No page contains a second mini-lesson.
Whitespace protects the operation.
