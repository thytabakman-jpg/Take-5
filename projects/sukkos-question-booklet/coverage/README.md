## Purpose

The lattice prevents narrow analysis from being mistaken for complete analysis.

It gives every audit a stable place to ask what is missing, irreducible, internal, external, isolated, or interactive at each scope.

## Authority boundary

A coverage file records a projection and routes findings.
It never owns final learner goals, philosophy, sources, page roles, copy, art, or project state.

Canonical truth lives in the authority registry.

## Closure

A 36-cell pass closes only when every applicable cell has a typed disposition and no result-sensitive OPEN or BLOCKED cell remains hidden.
