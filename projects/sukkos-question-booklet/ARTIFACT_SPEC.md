Page order.
Exact copy.

## Hard constraints

Readable at Grade 5–6 level.
No overflow.
No omitted source boundary.
No claim that Page 3's three checks exhaust all laws of s'chach.

No visual dependence on color alone.

No rabbinic portrait requirement.

## Free variables

Exact font family.
Exact warm palette values.
Minor illustration styling.
Exact decorative geometry.
Micro-spacing compatible with readability.
Deer-logo placement within bottom-corner constraint.

## Page acceptance

Every page contains:
correct title,
correct major operation,
required visible text,
required visual object,
bottom handoff or transfer,
deer logo,
no unauthorized content.

## Set acceptance

Exactly four pages.
All four page identities occur once.
Question-coordinate symbols stay consistent.
Sukkos reveal occurs on Page 3.
Page 4 is understandable without Page 3's holiday content.
The whole route reads as one transformation.

## Render boundary

A renderer can choose only FREE variables.
A renderer cannot rewrite student copy or source claims.
