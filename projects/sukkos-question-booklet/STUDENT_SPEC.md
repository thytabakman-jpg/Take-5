# Student Specification

Status: LOCKED_FOR_RENDER_CANDIDATE
Date: 2026-09-27

## Audience

Grade 5–6.

## Reading target

Short blocks.
Concrete nouns and verbs.
Technical terms only when they perform real work.

## Student-facing question model

Target
What exactly am I trying to find out?

Relevant facts
What information matters to this question?

Answer test
What would count as settling it?

Symbolic form:

Q = <T, F, R>

T = target.
F = relevant facts or context.
R = resolution condition, presented to students as the answer test.

## Developmental protection

The backend model retains issue, answer space, presuppositions, and resolution conditions.

The student surface compresses those into three coordinates because exposing the larger backend object adds vocabulary without adding required Page 3 or Page 4 performance.

## Learner evidence

Page 1:
student predicts which yes/no question removes possibilities.

Page 2:
student identifies a missing Target, Relevant fact, or Answer test in a weak question.

Page 3:
student refuses to classify the mystery branch until asking whether it is detached.

Page 4:
student repairs a vague route question without a Sukkos scaffold.

## Emotional safety

No personal disclosure is required.

A final own-question prompt is optional.

## Public completeness

Every fact needed for the core task appears on the booklet.

No teacher explanation carries a required conceptual bridge.
