# Source Boundary

Status: CURRENT PROTECTION

## Three layers

SOURCE CONTENT
→ INTERPRETATION
→ EDUCATIONAL APPLICATION.

A source can support the project without literally stating the child-facing model.

## Record format

Each admitted source receives source identity, original language where needed, translation, native context, what the source directly licenses, interpretive move, student-facing application, and what is not claimed.

## Failure conditions

Prestige used in place of a missing bridge.
Educational analogy described as the source's literal meaning.
Holiday source used to smuggle Page 3 into Page 2.
Translation that changes the operative distinction.
Citation without a learner-facing function.
