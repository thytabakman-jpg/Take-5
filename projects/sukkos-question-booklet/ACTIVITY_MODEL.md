# Activity Model

Status: LOCKED_ANALYTICALLY / EMPIRICAL TEST PENDING
Date: 2026-09-27

## Page 1 activity

Object:
eight visible cards built from three binary attributes.

Attributes:
circle or square,
striped or plain,
star or moon.

Task:
track which possibilities remain after each yes/no answer.

Observable evidence:
learner can identify a question that separates the remaining possibilities.

Failure diagnosis:
learner treats the question as wording only and does not track the live set.

## Page 2 activity

Object:
one vague question.

Task:
identify the missing or weak Target, Relevant facts, and Answer test.

Observable evidence:
learner can point to the coordinate creating ambiguity.

## Page 3 activity

Object:
four s'chach material cards.

Task:
classify each card under the three displayed source checks.

Critical event:
the mystery leafy branch lacks attachment status.

Observable evidence:
learner refuses premature classification and asks whether the branch is detached.

Failure diagnosis:
learner guesses PASS or FAIL without identifying missing information.

## Page 4 activity

Object:
two-route travel case.

Facts:
Route A takes 12 minutes.
Route B takes 9 minutes plus a 5-minute construction delay today.

Weak question:
Which way is better?

Task:
construct Target, Relevant facts, Answer test, then rewrite the question.

Observable evidence:
the rewritten question specifies fastest walking route today or an equivalent criterion grounded in the given facts.
