# Governing Goal

Status: CURRENT HIGH-LEVEL GOAL
Authority: learner outcome and project success target

## Formal goal object

G = <X, T, I, Sigma>.

X = Grade 5–6 learner in a one-session Sukkos learning setting.

T = move from a thin model of a question as merely "something you ask" toward a usable structural model that lets the learner construct or improve a question.

I = one four-page public Sukkos booklet using real mathematical or logical structure, a Jewish conceptual operation, a Sukkos-native embodiment, and independent transfer.

Sigma = on a new case, the learner can identify what the question is trying to find out, identify information or constraints that matter, state what kind of answer would resolve the question, and revise the wording or structure accordingly.

## Protected constraints

The goal is distinct from constraints.

Current protected constraints include four public pages, Grade 5–6 accessibility, one-session usability, no hidden facilitator bridge, real intellectual work from mathematics or logic, explicit is/ought boundary, meaningful Sukkos surplus, source/interpretation/application separation, independent Page 4 transfer, durable Markdown state, and localized change control.
