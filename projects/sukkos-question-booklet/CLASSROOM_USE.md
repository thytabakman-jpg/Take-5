# Classroom Use

Status: CORE USE LOCKED / EMPIRICAL VALIDATION PENDING
Date: 2026-09-27

## Core materials

One booklet per learner.
Pencil.

No additional materials are required for the core route.

## Facilitation boundary

Learners read the public text and inspect the visuals.

An adult can:
manage timing,
invite learners to compare answers,
read Hebrew or English aloud,
clarify task mechanics already present on the page.

An adult does not supply:
the three-part question model,
the source-to-application bridge,
the missing Page 3 question,
the Page 4 rewritten question.

## Approximate classroom movement

Page 1:
individual prediction, then brief comparison.

Page 2:
read source and inspect the question model.

Page 3:
classify cards and stop at the mystery branch until someone identifies the missing fact.

Page 4:
independent written transfer, then optional sharing.

## Optional extension

An edible sukkah model can follow the core booklet as a separate craft.

It is explicitly a model and is not evidence that edible materials are valid s'chach.

It does not replace the Page 3 source-grounded classification task.

## Validation observations

Record:
whether learners identify the missing Page 3 question without prompting,
whether learners use all three coordinates on Page 4,
which wording causes confusion,
whether the source distinction survives without adult paraphrase,
whether visual cues support or distract from reasoning.

These observations update CLASSROOM_VALIDATION state without rewriting the accepted route automatically.
