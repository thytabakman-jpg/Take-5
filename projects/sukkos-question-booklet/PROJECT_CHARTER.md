# Project Charter

Status: CURRENT BOOTSTRAP AUTHORITY
Authority: project purpose, scope, constraints, and success frame

## Purpose

Create a four-page Sukkos booklet that leaves a Grade 5–6 learner with a clearer basic model of questions and a usable way to ask a better question.

## Audience and setting

Audience: Grade 5–6.
Setting: one bounded classroom session.
Use mode: public student-facing artifact with shared inquiry.
Facilitator role: logistics, safety, timing, and conversation process only. Required conceptual bridges must exist in the public artifact.

## Governing learner outcome

At the end of the booklet, a learner can take a vague or incomplete question and improve it by identifying the information target and the conditions that make the question answerable.

The exact student-facing decomposition remains OPEN until QUESTION_MODEL.md closes it.

## Holiday requirement

Sukkos must do more than decorate or illustrate the lesson.

The Sukkos page must instantiate, constrain, deepen, or physically enact the same operative structure developed earlier in the booklet. Replacing Sukkos with a generic craft must remove an educationally important function.

## Form requirement

Exactly four public pages.

Four pages describe artifact topology, not the number of backend analysis files.

## Backend requirement

The project keeps separate durable Markdown authorities for learner transformation, question mathematics, philosophy, is/ought boundary, Jewish source logic, Sukkos embodiment, page route, art direction, exact copy, activity mechanics, project state, decisions, lessons, risks, tool runs, and 36-cell coverage.

## Non-goals

This project does not create a universal theory of Jewish education.
This project does not treat every prior Sukkos booklet choice as binding.
This project does not let a renderer invent curriculum.
This project does not let copy edits redefine philosophy or learner goals.
This project does not equate the 36 coverage cells with 36 student pages.

## Project success

1. The four-page route is causally coherent.
2. Each page has one major learner move.
3. Each page creates or earns the next page's question.
4. The mathematical/question model is accurate enough for the intended lesson.
5. The move from descriptive structure to educational/Jewish value is explicit rather than smuggled through analogy.
6. Sukkos adds holiday-native surplus.
7. A learner performs independent transfer on Page 4.
8. Exact copy, visuals, sources, and activity mechanics survive render QA.
9. Changes remain traceable to the authority they alter.
10. Open coordinates remain typed OPEN rather than filled by convenience.
