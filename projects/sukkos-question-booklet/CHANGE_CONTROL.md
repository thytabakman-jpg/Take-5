# Change Control

Status: CURRENT

## Change object

Delta = <request, owning_object, old_state, proposed_state, reason, dependencies, tests, decision, receipt>.

## Locality rule

Change the smallest authority that actually owns the requested property.

A wording preference does not automatically reopen the learner goal.
A learner-goal change reopens dependent page roles and copy.
A source correction reopens any interpretation, application, or page function that depended on the incorrect reading.
A visual change reopens pedagogy only when it alters the learner operation or handoff.

## Impact pass

After an admitted change, inspect direct dependents, cross-page handoffs, source boundaries, learner-state transitions, visual obligations, exact copy, open questions, and coverage cells.

## Preservation

Passing unaffected state is protected.

No clean rebuild occurs merely because one defect exists.

## History

DECISION_LOG.md records admitted choices.
LESSONS_LEDGER.md records durable lessons from failures.
CURRENT_STATE.md records the live state after each material change.
