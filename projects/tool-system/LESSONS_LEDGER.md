# Tool System Lessons Ledger

Append-only.

## 2026-09-27 L001

Project structure works best when each load-bearing concern has one canonical
owner instead of one giant document trying to preserve everything.

## 2026-09-27 L002

The 36-cell coverage surface prevents dimension collisions only when each cell is
physically distinct and cannot rewrite another cell.

## 2026-09-27 L003

A current-state file is useful only when it is a projection over retained history,
not the history itself.

## 2026-09-27 L004

Tool name, mathematics, configured identity, runtime realization, invocation, run,
receipt, and closure are distinct objects.

## 2026-09-27 L005

Equal cardinality is not identity. Scope x ModeFace and SourceScope x TargetScope
both contain 36 cells but perform different jobs.

## 2026-09-27 L006

Organization is an anti-loss measure only when generation and updates fail closed
on overwrite and when CI checks inventory parity.
