# Regression contract: ProjectManager

A valid package keeps all of these true:

- required core files exist
- exactly 36 Scope x ModeFace coverage pages exist
- coverage pages are audit evidence, not semantic authority
- the distinct SourceScope x TargetScope surface is not merged into coverage
- decisions, lessons, runs, and evidence are append-only
- package generation never overwrites changed existing files
- current configured tools have one package each
- aliases do not create duplicate mutable authority
- missing semantics/runtime/evidence remain typed OPEN


## Pre-project admission invariants

- ProjectDefinitionCandidate can be assessed without a 21-coordinate full project package
- D0 has the declared nine coordinates G,C,K,M,R,E,B,A,O
- complete candidate without USER approval is DEFINITION_READY, not PROMOTION_READY
- blocking OPEN preserves EXPLORATION_OPEN
- TOOL or controller approval cannot impersonate USER approval
- USER approval permits PROMOTION_READY but does not itself create a full project
- candidate exploration remains EVIDENCE_ONLY before promotion
- ProjectDefinitionCandidate and ManagedProject cannot be simultaneously bound as one state
- the full configured MT -> PD -> GOAL -> GOAL witness remains stable on second supervisory pass
- existing managed-project behavior remains preserved
