# Lessons ledger: ProjectManager

Append-only.

## 2026-09-27 L001

Separating dimensions into owned pages prevents one analysis dimension from
silently rewriting another.

## 2026-09-27 L002

Current projection, historical evidence, semantic authority, runtime reality,
and run evidence are different objects and require different owners.


## 2026-09-27 L003

A capability is not fully integrated merely because runtime and architecture were updated.
The current-tool package also needs its projections, dependencies, protections, handoffs,
and regression contract synchronized so future recovery does not reconstruct a stale tool.
