# 36-cell coverage: MultiObject

Surface: Scope x ModeFace.
Role: audit / discovery / regression evidence only.
Cells: 36.

Each cell owns findings for one coordinate. A finding becomes canonical only
through the authority and change-control path.

## Use and ownership

Reader: MultiObject maintainers and audit reviewers.
Purpose: Find the evidence-only Scope x ModeFace cells and preserve unresolved questions; no cell is a second mathematical authority.

- [MultiObject authority registry](../AUTHORITY_REGISTRY.md)
- [Change control](../CHANGE_CONTROL.md)
- [Source map and provenance](../SOURCE_MAP.md)
- [Separate directed handoff surface](../HANDOFF_SURFACE.md)

A cell marked OPEN has no admitted cell-specific finding yet. It does **not** negate findings recorded in research, prove that no relation exists, or mark the native MultiObject runtime OPEN.
