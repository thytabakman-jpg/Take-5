### A-OPEN-001 — External name to single working tool ID

Take-5 registers `Architecture`; the Reaserch formal mathematical object is
`ARCHITECTURE-ANALYSIS` and its user-facing label is `Architect`. The current
[identity](IDENTITY.md) and [source map](SOURCE_MAP.md) keep the distinct
source/authority roles visible. An actually executed user-entry resolver that
sends `Architect` to the one admitted `Architecture` configured run, without
minting a second tool or silently downgrading the requested profile, has **not
yet been demonstrated**. A repository prose link cannot prove a host dispatch.

**Closure discriminator:** Trace and test each supported named invocation
through actual name resolution, exact registered tool ID, manifest, configured
wrapper, native adapter, execution receipt, and user-visible completion truth.
Include an unknown-alias negative case and preserve unsupported host entry as
OPEN/BLOCKED. Owner: working Take-5 invocation/dispatch integration.

### A-OPEN-002 — GOAL hierarchy and 36-surface compatibility

Take-5 `Architecture` has configured `Scope × ModeFace` coverage and a native
architecture-analysis function. Reaserch's governed GOAL–Architect contract
requires typed same-level pairing, represented-parent ascent, cross-level
reconciliation and reentry and speaks of a separate directed 36-surface.
No executable cross-repository binding establishing that the Take-5 tool
performs that entire contract was verified in the current routing repair.

**Closure discriminator:** On an exact current executable basis, test a
hierarchical GOAL+Architect case with a represented parent and a failure/OPEN
case, verify the correct typed 36-surface, pairing receipt, parent reconciliation,
and reentry. Reject local Architecture completion as proof of global GOAL
completion. Preserve the separate repositories' authorities until any
integration is admitted. Owner: Take-5 runtime/integration and Reaserch
GOAL–Architect contract owner under their own change controls.

These are specific **integration evidence gaps**, not a claim that the separate
mathematical documents are incorrect or that every invocation path fails.
