The registered Take-5 configured-tool ID is `Architecture`; the current registry and
manifest bind that exact ID. `Aliases: none` means this package does **not** claim
that `Architect` or `ARCHITECTURE-ANALYSIS` is a second registered ID or an
already admitted runtime alias. Reaserch uses `ARCHITECTURE-ANALYSIS` for its
basis-relative formal mathematical object and `Architect` as a user-facing name.

A caller using either external label must resolve it through an explicitly
admitted name/contract binding before claiming execution of the Take-5
`Architecture` runtime. An absent, ambiguous, or incompatible binding remains
OPEN/BLOCKED rather than choosing a similarly named definition by convenience.
