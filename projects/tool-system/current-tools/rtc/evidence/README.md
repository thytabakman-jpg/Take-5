# Evidence: RTC

Create a new uniquely named record for each material entry.

## Evidence role and admission

Reader: RTC maintainers and audit reviewers. Retain source-attributed tool-specific evidence without treating it as executed C48, admitted mathematical authority or a completed protected-set proof. Retrieve the [source map](../SOURCE_MAP.md), [authority registry](../AUTHORITY_REGISTRY.md) and [change control](../CHANGE_CONTROL.md) before admitting findings. Evidence is distinct from configured [run receipts](../runs/README.md) and superseded [history](../history/README.md).
