# Run evidence: RTC

This directory is append-only.
Create a new uniquely named record for each material entry.

## Run-evidence role and admission

Reader: RTC operators and validation reviewers. Admit only an actually witnessed RTC or C48 invocation with inputs, source revision, observed result, native checks and limitations. A plan, generic CI green status, package registration or prose source link is not a new RTC run. See the [runtime entrypoint](../RUNTIME.md), [native regressions](../REGRESSION_CONTRACT.md) and [open preservation question](../OPEN_QUESTIONS.md).
