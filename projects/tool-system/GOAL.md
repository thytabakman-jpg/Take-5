# Tool System Goal

Status: CURRENT
Date: 2026-09-27

## Governing goal

Keep the complete Take-5 tool and ICC ecosystem durably organized so every live
configured tool and every recovered historical or unresolved ICC/IC variant has
one identifiable project package, one authority route for each mutable object,
retained history and evidence, explicit OPEN state, non-overwriting change
control, and regression protection that detects new inventory or damaged
organization without rebuilding unaffected state.

## Success condition

The goal is satisfied relative to the current basis when:

- current registry and package inventory are in exact parity;
- every package has its required owned control surfaces and 36 Scope x ModeFace
  coverage pages;
- the separate SourceScope x TargetScope handoff surface remains distinct;
- evidence, runs, decisions, lessons, and history are retained append-only;
- existing semantic/runtime authorities are referenced rather than duplicated;
- every admitted material change routes through one canonical owner;
- validation and capability preservation pass;
- remaining unknown historical identities are typed OPEN with a resume condition.

Closure is basis-relative. New tools, variants, or recovered identity evidence
reopen only the affected cone.
