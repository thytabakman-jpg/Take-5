# Classroom Use
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

Adult may invite observation, read source text, clarify vocabulary, ask bridge questions, manage time.

Adult does not supply the Page-2 question, the Page-3 conclusion before inspection, or the Page-4 question.

Primary observation: can learner move from an unknown state to a self-generated question?
Secondary: can learner explain why the question helps?
