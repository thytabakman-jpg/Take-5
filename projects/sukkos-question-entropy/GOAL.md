# Goal

Status: CURRENT

G = <X,T,I,Sigma>

X
A four-page Grade 5–6 Sukkos booklet built on Shannon entropy and question-driven uncertainty reduction.

T
A render-ready artifact in which the learner moves from an explicit live possibility set to one self-authored question that reduces uncertainty, while understanding the Sukkos surplus that distinction need not become separation.

I
Complete route, exact copy, sources, visuals, image-generation constraints, classroom mechanics, and verification without collapsing this project into the mutual-information route.

Sigma
No hidden facilitator bridge.
No entropy = disorder metaphor.
No claim that every question reduces uncertainty.
No claim that taste/smell halachically identifies the four species.
No Page 4 worksheet grid.
No photorealistic art.
No loss of deer-logo/house identity.
No renderer-authored curriculum.
