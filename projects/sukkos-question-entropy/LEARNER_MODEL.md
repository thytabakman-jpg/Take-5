# Learner Model

Status: LOCKED FOR CURRENT ROUTE

## Entry state

Learner understands ordinary questions but can struggle to generate one when faced with uncertainty.

## Target skill

Given several live possibilities, learner can:
1. identify what remains unknown;
2. choose a distinction that splits the live possibilities;
3. turn that distinction into a question;
4. update what remains possible after an answer.

## Observable evidence

The learner independently writes or says one question in a novel Page 4 scene and can point to which possibilities its answer would remove.

## Emotional movement

confusion
→ visible possibilities
→ one move is available
→ distinctions clarify
→ difference does not require separation
→ I can ask instead of guessing.

Personal disclosure is not required.
