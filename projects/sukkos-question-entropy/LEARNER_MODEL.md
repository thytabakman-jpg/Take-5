# Learner Model
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

Audience: Grade 5-6.
High-value case: learner understands questions but struggles to generate one from scratch.

Design consequence: questioning is shown as an operation with visible steps, not as a personality trait.

Protected dignity: no diagnosis, no public disclosure requirement, no implication that difficulty asking means low intelligence, no dependence on spontaneous verbal performance.

Success: learner independently constructs a question on Page 4.
