# Mathematics Model — Shannon Entropy

Status: LOCKED_RELATIVE FOR CURRENT ROUTE

## Formal object

For a discrete random variable X:

H(X) = -Σ_x p(x) log2 p(x)

H(X) measures expected surprisal and, in the finite classroom model, uncertainty about which outcome is the hidden one.

## Classroom model

Use eight equally likely illustrated cards.

Before any answer:
H(X) = log2(8) = 3 bits.

A balanced yes/no question divides the possibilities 4/4 and leaves four live possibilities:
3 bits → 2 bits.

Then:
2 bits → 1 bit.
1 bit → 0 bits.

Visible sequence:
8 → 4 → 2 → 1
and
3 → 2 → 1 → 0 bits.

## Accuracy boundaries

Entropy is not physical messiness, chaos, badness, or emotional disorder.

Not every grammatical question lowers entropy.
A question with the same answer for every live possibility removes nothing.

The formula remains visible without requiring Grade 5–6 learners to calculate logarithms.

## Student sentence

"Entropy gives us a way to measure how much uncertainty is left."
