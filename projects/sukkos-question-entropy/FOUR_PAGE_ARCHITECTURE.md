# Four-Page Architecture
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

Status: BACKEND LOCKED

Whole movement
IS / measurable uncertainty -> HUMAN TECHNOLOGY / questions reduce it -> SUKKOS SURPLUS / distinguish accurately, then bind together -> TRANSFER / I can build my next question.

Page 1 — IS
Job: make uncertainty mathematically real.
Anchor: Shannon entropy.
Exit: "not knowing" can have structure.
Bridge: If uncertainty can be measured, what can we do to make it smaller?

Page 2 — HUMAN TECHNOLOGY
Job: turn Page-1 reality into a usable question-making procedure.
Operation: unknown -> possibilities/distinction -> construct question -> update.
Scaffold: WH + auxiliary/modal + subject + main verb.
Emotional job: convert blankness into a next move.
Bridge: Can Sukkos show us what happens when distinctions help us tell possibilities apart?

Page 3 — SUKKOS SURPLUS
Job: add a Sukkos-native religious operation.
Source: Vayikra Rabbah 30:12 differentiates four symbolic types through taste/smell, then binds them into one grouping.
Operation: distinguish accurately -> understand difference -> reintegrate the differentiated whole.
Exit: difference can carry information without becoming separation.
Bridge: Can I use questions to tell possibilities apart and still keep sight of the whole?

Page 4 — TRANSFER
Job: independent question generation.
Move: given a new uncertainty, identify live possibilities, build a question, explain how an answer reduces them.
Emotional job: earned agency.
Closing: What do I not know yet, and what question can I build to make the possibilities smaller?
