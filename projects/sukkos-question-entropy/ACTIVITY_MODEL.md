# Activity Model
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

P1 evidence: compare two balanced possibility spaces and identify which has more uncertainty.
P2 evidence: assemble at least one canonical WH-question and state its unknown.
P3 evidence: reconstruct the Midrash's four symbolic combinations and explain the move to one grouping without attributing entropy to the source.
P4 evidence: independently name unknown, identify live possibilities/distinction, construct a question, explain how answers change possibilities.

Completion without independent question production is not transfer evidence.
