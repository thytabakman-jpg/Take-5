# Project Charter

Status: DEFINITION READY / USER PROMOTION AUTHORITY PRESENT

## Purpose

Create a four-page Sukkos booklet that lets Grade 5–6 learners experience uncertainty as a structured state and use questions as a practical way to reduce it.

## Audience

Grade 5–6.
One bounded classroom session.
The student-facing artifact carries every load-bearing conceptual bridge.

## Governing learner transformation

Entry:
"I do not know, so I guess, freeze, or wait."

Exit:
"I can name what is still possible and build a question whose answer reduces the live possibilities."

## Holiday requirement

Sukkos contributes more than decoration.
Page 3 uses a Sukkos-native source in which distinctions remain real while the differentiated parts belong to one whole.

## Form

Exactly four portrait pages.
Illustrated, not photorealistic.
Small deer logo on every page.
No rabbinic portraits.
No blue-gray box system.
No generic worksheet page.

## Success

1. Page 1 honestly teaches entropy as uncertainty over possibilities.
2. Page 2 turns that into a usable question-making technology.
3. Page 2 includes שואל כענין without revealing Sukkos early.
4. Page 3 uses Vayikra Rabbah 30:12 accurately as symbolic classification.
5. Page 3 adds the one-group move after distinction.
6. Page 4 is an immersive transfer scene, not a worksheet.
7. The learner authors a question in a new case.
8. Art performs the main explanatory work.
9. Mathematical and Jewish claims survive QA.
10. A renderer cannot rewrite curriculum.
