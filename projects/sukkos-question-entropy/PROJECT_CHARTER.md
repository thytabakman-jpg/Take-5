# Project Charter

> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

## Purpose

Create a four-page Sukkos booklet that begins with a real mathematical account of uncertainty, turns questioning into a usable human technology, shows a genuine Sukkos-native religious surplus, and ends with independent transfer.

## Governing learner change

The learner moves from an undifferentiated "I don't know" state to being able to:
1. identify the live uncertainty;
2. build an information-seeking question;
3. use an answer to reduce the possibility space;
4. repeat the move independently.

## Holiday requirement

Sukkos must do more than provide an example. Page 3 must add a religious operation to the Page-2 human technology.

Current holiday route:
Leviticus 23:40 plus Vayikra Rabbah 30:12. The Midrash differentiates four symbolic types using taste/smell and then conceptually reintegrates them as one grouping.

## Form

Exactly four student pages.
One major job per page.
Page 2 and Page 4 carry the strongest emotional agency.
No required personal disclosure.
No front-end rendering until the backend lock is satisfied.
