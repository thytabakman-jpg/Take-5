## HOW MUCH DON'T WE KNOW?

One card is hidden.

There are 8 possibilities.

That uncertainty has a number.

H(X) = -Σ p(x) log₂ p(x)

For 8 equally likely possibilities:

3 bits of uncertainty

ASK

Is it a circle?

8 → 4
3 bits → 2 bits

ASK

Is it striped?

4 → 2
2 bits → 1 bit

ASK

Does it have a star?

2 → 1
1 bit → 0 bits

Entropy tells us how much uncertainty is left.

If uncertainty can get smaller, what can we do to make it smaller?

A question is not useful just because it ends with a question mark.

A useful question changes what is still possible.
