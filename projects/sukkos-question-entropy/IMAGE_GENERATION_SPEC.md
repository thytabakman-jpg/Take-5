# Image Generation Specification

Status: LOCKED FOR FIRST RENDER

## Production mode

Generate each full page as a composed image-first educational page.

Generate all four pages as one coordinated visual campaign so line quality, illustration language, palette, typography feel, and deer logo remain coherent.

## Global visual constraints

Portrait educational booklet page for Grade 5–6.
Warm cream paper.
Editorial children's nonfiction illustration.
Hand-drawn vector/gouache hybrid feel.
Clean strong hierarchy.
Subtle Sukkos warmth.
No photorealistic people.
No glossy 3D.
No blue-gray UI panels.
No corporate slide aesthetic.
No generic worksheet.
No rabbinic portraits.
No childish clip art.
No decorative clutter.
Generous whitespace.
Tiny simple deer logo in bottom corner.

## Copy control

All visible wording comes from EXACT_COPY.md.
Renderer does not paraphrase.
Mathematical symbols remain legible.
No tiny body copy.

## Page 4 non-negotiable

One cinematic story scene.
One large speech bubble.
No ruled answer table.
No multi-box worksheet.
No checklist grid.

## Failure conditions

Fail a render when:
the artwork can be replaced by clip art without losing the concept;
Page 4 reads as a worksheet;
the formula is garbled;
the four-species matrix is confusing;
the pages do not look like one series.
