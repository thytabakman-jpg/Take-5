# Question Construction
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

Status: BACKEND LOCKED AS SCAFFOLD

Epistemic operation
1 Name what is unknown.
2 Identify live possibilities or a distinction that would reduce them.
3 Ask for information.
4 Update the possibility space.

Language scaffold for a high-value class of English WH-questions
WH/question word + auxiliary/modal + subject + main verb.
Example: Where + do + you + live?

Boundary: not universal. Subject-WH questions can omit auxiliary inversion, e.g. "Who called?"

Design reason: the learner receives both a reason to ask and pieces from which to build.
