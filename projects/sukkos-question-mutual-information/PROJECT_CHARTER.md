# Project Charter

Status: DEFINITION READY / USER PROMOTION AUTHORITY PRESENT

## Purpose

Create a four-page Sukkos booklet that lets Grade 5–6 learners see that information is relational: a clue or answer is useful when it changes what they know about a chosen target.

## Audience

Grade 5–6.
One bounded classroom session.
Every load-bearing bridge appears in the student-facing artifact.

## Governing learner transformation

Entry:
"I can produce questions, but I do not reliably aim them at what I need to know."

Exit:
"I can name my target and build a question whose answer gives information about that target."

## Holiday requirement

Sukkos contributes a native case in which particular distinctions organize a symbolic classification, followed by a move from differentiated types to one group.

## Form

Exactly four portrait pages.
Illustrated, not photorealistic.
Small deer logo on every page.
No rabbinic portraits.
No blue-gray box system.
No generic worksheet page.

## Success

1. Page 1 honestly introduces mutual information as reduction of uncertainty about a target.
2. Page 1 visibly contrasts informative and irrelevant questions.
3. Page 2 gives a target-first question procedure.
4. Page 2 uses שואל כענין as Jewish inquiry discipline.
5. Page 3 uses Vayikra Rabbah 30:12 accurately as symbolic classification.
6. Page 3 adds one-group integration after differentiation.
7. Page 4 requires a learner-authored target-relevant question.
8. Page 4 is a scene, not a form.
9. Art carries the distinction between relevant and irrelevant information.
10. Renderer cannot rewrite curriculum.
