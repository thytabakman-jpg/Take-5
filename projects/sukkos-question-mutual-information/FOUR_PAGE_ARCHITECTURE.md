# Four-Page Architecture

Status: LOCKED FOR RENDER CANDIDATE

## Whole movement

NAME THE TARGET
→ FIND INFORMATION THAT BEARS ON IT
→ ASK TO THE POINT
→ DISTINGUISH WITHOUT SEPARATING
→ ASK WHAT YOU ACTUALLY NEED TO KNOW

## Page 1 — DOES THIS CLUE TELL YOU ANYTHING?

Job:
make target-relative information visible.

Visual:
one hidden-card target plus two possible questions.

Question A:
"Is it striped?"
Its answer divides the target possibilities.

Question B:
"Is it made of paper?"
Every live card is paper, so the answer changes nothing about which card is hidden.

Equation:
I(X;Y) = H(X) - H(X|Y)

Exit:
some answers tell us about the target; others do not.

Bottom handoff:
"What makes one question more useful than another?"

## Page 2 — ASK TO THE POINT

Job:
give a target-first question procedure.

Visual:
one large target symbol in the center; information arrows either connect to it or pass by it.

Source ribbon:
שואל כענין — ask according to the matter.

Procedure:
1. What am I trying to know?
2. What answer would change what I know about it?
3. Build that question.

Small construction scaffold:
question word + helper verb + subject + main verb.
Yes/no questions can begin with the helper verb.

Exit:
usefulness depends on the target.

Bottom handoff:
"Can Sukkos show us a case where the right differences reveal what we are looking at?"

## Page 3 — WHICH DIFFERENCES MATTER HERE?

Job:
Sukkos-native embodiment.

Visual:
the Midrash's 2×2 taste/smell grid.
Taste and smell are the distinctions that locate each species in this symbolic map.
Then all four move visually into one group.

Exit:
the right distinction depends on the target, and accurate distinctions need not become separation.

Bottom handoff:
"When I need to know one thing, can I ask about that instead of everything around it?"

## Page 4 — ASK WHAT YOU NEED TO KNOW

Job:
independent transfer with emotional payoff.

Scene:
You need to know whether a classmate knows the correct after-school pickup time.
Around the scene are lots of visible but irrelevant details: backpack color, weather, snack, sports shirt.

Learner task:
write one question in one oversized speech bubble whose answer would actually tell you about the pickup-time target.

No checklist.
No coordinate boxes.
No forced personal disclosure.

Closing:
"More information is not the same as the information you need."
