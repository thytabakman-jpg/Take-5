# Sukkos Question Booklet — Mutual Information Route

Status: PRODUCTION PACKAGE CANDIDATE
Date: 2026-09-28
Owner: ProjectManager

Independent four-page Grade 5–6 Sukkos booklet.

Core mathematics:
I(X;Y) = H(X) - H(X|Y)

Core student idea:
A useful question gives information about the thing you are actually trying to know.

Movement:
target → relevant information → ask to the point → Sukkos distinguishes and reunites → ask what you actually need to know.

This project owns its own goal, model, sources, script, visual system, render specification, classroom use, verification, decisions, and state. It does not inherit copy from the Shannon route.
