# Image Generation Specification

Status: LOCKED FOR FIRST RENDER

## Production mode

Generate the four pages as a coordinated image-first series.
Do not construct them as generic document layouts with decorative illustrations added later.

## Global visual constraints

Portrait Grade 5–6 booklet page.
Warm cream paper.
Editorial children's nonfiction illustration.
Hand-drawn vector/gouache hybrid.
Clean hierarchy.
Warm, intelligent, emotionally safe.
No photorealistic people.
No glossy 3D.
No blue-gray UI system.
No corporate infographic style.
No generic worksheet.
No rabbinic portraits.
No childish clip art.
Tiny simple deer logo in bottom corner.

## Copy control

Visible text comes from EXACT_COPY.md.
Renderer does not rewrite.
Equation remains exact and readable.
Hebrew phrase remains exact.

## Page 1 non-negotiable

The difference between STRIPED? and PAPER? must be visible before reading the explanation.
The first changes the target set.
The second does not.

## Page 4 non-negotiable

One story scene.
One obvious target.
Several irrelevant visual details.
One large speech bubble.
No list of answer fields.
No three-column model.

## Failure conditions

Fail a render when:
relevance is conveyed only through color;
the equation is garbled;
Page 3 implies halachic species identification;
Page 4 reads as a worksheet;
the series looks unlike the Yom Kippur/Sukkos house style.
