# Activity Model
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

P1 evidence: given a target and two clues, learner identifies which clue changes what can be known about the target.
P2 evidence: learner names a target, selects a relevant distinction, and assembles a canonical WH-question.
P3 evidence: learner reconstructs the Midrash's symbolic mapping and identifies the shift from classification to one grouping without attributing mutual information to the source.
P4 evidence: learner independently names target, rejects an irrelevant distinction, constructs a relevant question, and explains how possible answers update the target.

A grammatically correct but target-irrelevant question does not satisfy transfer.
