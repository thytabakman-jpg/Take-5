# Learner Model
> Governing authority: GOAL.md. This file may specialize the governing goal but may not override it.

Audience: Grade 5-6.
High-value case: learner understands questions but struggles to decide what to ask and generate a question from scratch.

Design consequence: externalize the sequence target -> useful distinction -> question form.

Protected dignity: no diagnosis, no public disclosure requirement, no implication that question difficulty means low intelligence, no dependence on spontaneous verbal performance.

Success: learner independently names a target and constructs a question relevant to it on Page 4.
