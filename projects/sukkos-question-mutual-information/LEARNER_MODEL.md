# Learner Model

Status: LOCKED FOR CURRENT ROUTE

## Entry state

Learner can ask ordinary questions but may choose questions that are grammatical yet irrelevant to the information target.

## Target skill

Given a target X, learner can:
1. state what they want to know;
2. inspect a possible question or clue Y;
3. ask whether the answer would change what they know about X;
4. build a question with a target-relevant answer.

## Observable evidence

In a new Page 4 scene, the learner independently writes one question whose answer bears directly on the stated target and can explain what the answer would tell them.

## Emotional movement

lots of information
→ not all of it matters
→ choose the target
→ aim the question
→ distinctions can clarify without dividing people
→ ask what you actually need to know.

Personal disclosure is not required.
