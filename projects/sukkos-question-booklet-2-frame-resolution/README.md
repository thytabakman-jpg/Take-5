**Status:** derived project entry; consult [typed project state](PROJECT_STATE.json) for currentness and [goal](GOAL.md) for accepted educational purpose. This README does not approve production or change the booklet.

## Project identity

This is the separately managed Grade 5–6 four-page Sukkos booklet studying **questions as frames**: students learn to recognize a built-in assumption, preserve genuine alternatives, state the condition that would settle the matter, and rewrite a question. It is not a revision whose goal can be silently substituted for the separately managed [Sukkos question booklet](../sukkos-question-booklet/README.md), which teaches target, relevant facts and answer test.
