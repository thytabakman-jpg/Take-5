# Question Model

Status: LOCKED FOR BUILD
Date: 2026-09-27

## Backend object

Let s be the live information context.

Use the project model:

q_s = <P, I_s>.

P
A set of presuppositional or background commitments treated as given by the question in the current use.

I_s
A contextual issue over s.

For this project, I_s is:
- nonempty,
- downward closed,
- composed of information states t subseteq s,
- covering s in the sense that the live alternatives are represented,
- resolving when t is in I_s.

The question is nontrivial at s when s itself does not already resolve the issue.

This is a synthesized project model drawing on question-presupposition theory and inquisitive semantics.
It is not asserted as the unique philosophical definition of question.

## Student projection

kappa(q_s) = <A,O,S>

A = ASSUMES
What does the wording already treat as true?

O = OPENS
What possibilities remain live?

S = SETTLES
What evidence or information state would count as resolving the issue?

Public student shorthand:

QUESTION = ASSUMES + OPENS + SETTLES.

## Ablation

Remove ASSUMES
A loaded question can pass unnoticed.

Remove OPENS
The learner cannot see which alternatives the wording has excluded.

Remove SETTLES
The learner can criticize wording without knowing what would answer the repaired question.

All three coordinates survive.
