# Goal

Status: CURRENT CANDIDATE EXTENSION / VALIDATION PENDING

G = <X,T,I,Sigma>

X
An idea or project-definition candidate, or an admitted managed project state, plus incoming evidence, requests, work, and authority state.

T
For a candidate, reach a durable definition-ready state without premature promotion.
For an admitted project, maintain a coherent current authority-bound project-control state with a typed goal gap, a legal executable work frontier, bounded change routes, verified consequences, and explicit OPEN, BLOCKED, or CONFLICT residue.

I
First determine whether an idea has earned project promotion.
After promotion, determine what is current, what remains between that state and the governing goal, and the next legal bounded work or project transition.

Sigma
No authority by recency.
No silent overwrite.
No WBS and schedule collapse.
No tool-output-to-truth shortcut.
No project mutation from observer-mode tool execution.
No candidate-to-project promotion without definition readiness and explicit USER approval.
No full project package required while a candidate remains exploratory.
No TransferCore mutation while its full identity is OPEN.
Every material admitted change receives impact, verification, state, and evidence updates.
