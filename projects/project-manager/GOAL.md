# Goal

Status: CURRENT

G = <X,T,I,Sigma>

X
A managed project state plus incoming evidence, requests, work, and authority state.

T
A coherent current authority-bound project-control state with a typed goal gap,
a legal executable work frontier, bounded change routes, verified consequences,
and explicit OPEN, BLOCKED, or CONFLICT residue.

I
For each managed project, determine what is current, what remains between that state
and the governing goal, and the next legal bounded work or project transition.

Sigma
No authority by recency.
No silent overwrite.
No WBS and schedule collapse.
No tool-output-to-truth shortcut.
No project mutation from observer-mode tool execution.
No TransferCore mutation while its full identity is OPEN.
Every material admitted change receives impact, verification, state, and evidence updates.
