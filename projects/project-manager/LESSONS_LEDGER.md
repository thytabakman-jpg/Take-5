# Lessons ledger

Status: APPEND-ONLY

## L001 Know the object before improving it

A tool name, runtime file, wrapper, or role description is not full identity.

Protection
ProjectManager has a full-math architecture artifact before promotion.

## L002 Project truth needs explicit owners

A later artifact cannot become authority merely because it is newer.

Protection
AUTHORITY_REGISTRY.md plus runtime owner validation.

## L003 One giant document causes overwrite

Different mutable project objects need explicit ownership and local deltas.

Protection
Separate project control surfaces and owner-local routing.

## L004 Coverage is evidence, not truth ownership

Thirty-six coverage cells expose blind spots but do not own project semantics.

Protection
Coverage files are evidence-only.

## L005 WBS is not schedule

Deliverable decomposition and temporal sequencing answer different questions.

Protection
Separate WBS.md and SCHEDULE.md plus regression test.

## L006 Tool result is evidence before admission

Execution success does not grant project authority.

Protection
Observer-only ProjectManager adapter plus separate admitted commit path.

## L007 Self-management needs no exemption

A manager that cannot survive its own rules creates hidden privileged state.

Protection
The ProjectManager project is managed as an ordinary project instance.

## L008 Safe transfer is target-authority preserving

Reusable learning cannot directly mutate another project.

Protection
TransferEvidenceCandidate remains evidence-only and non-authorizing.
