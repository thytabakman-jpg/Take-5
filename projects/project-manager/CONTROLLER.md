# ProjectManager project controller

Status: CURRENT PROJECT-LOCAL CONTROLLER

## Role

This controller organizes the ProjectManager build without becoming the author of every
dimension.

## Control loop

Bind project identity
-> recover current goal
-> read authority registry
-> validate 21 core project coordinates
-> bind incoming event or evidence
-> compute executable work frontier
-> route each proposed change to its canonical owner
-> impact-map dependencies and interfaces
-> execute substantive work through the selected governed capability
-> return results as evidence
-> admit a bounded project delta
-> verify
-> update current state, decisions, lessons, evidence, and handoffs
-> recompute frontier
-> reenter on material delta
-> close relatively or preserve OPEN, BLOCKED, or CONFLICT.

## Tool boundary

ProjectManager controls project state.
ImprovementCore controls autonomous substantive improvement work.
Configured domain tools control their native jobs.
Transfer reuse remains evidence-only until TransferCore is recovered and current.

## Anti-loss

No canonical fact exists only in chat.
No coverage cell owns editable truth.
No mutable object has more than one canonical owner.
A new artifact does not supersede an old authority by recency.
A local fix does not trigger a clean rebuild of unaffected accepted state.
