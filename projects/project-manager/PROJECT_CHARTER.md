# Project Charter

Status: CURRENT SELF-PROJECT AUTHORITY

## Purpose

Create and maintain a reusable Take-5 ProjectManager formal tool that can control any
project through explicit identity, goal, authority, state, decomposition, change,
evidence, verification, and handoff surfaces without becoming the domain solver.

## Scope

The project includes the ProjectManager mathematical object, native runtime,
configured-tool registration, protected behavior manifest, regression tests,
self-managed project package, 36-cell coverage evidence, ImprovementCore integration,
safe TransferCore evidence boundary, research basis, and requested bootstrap receipts.

## Success

The tool has one exact current identity.
A normal direct invocation resolves to the full configured tool.
The full run carries D36_C, 22 question families, four cognitive operators, closure,
reentry, and HF002 recurrence.
The native runtime validates project packages and authority.
A project change routes to the smallest owning authority and triggers impact reentry.
OPEN and CONFLICT remain explicit.
WBS and schedule remain separate.
The tool can manage this project with no special bypass.
ImprovementCore can consume the evidence-only work frontier.
TransferCore admission cannot mutate a target; a unique target authority binding and separate explicit mutation authorization are required.
Repository validation passes before canonical promotion.

## Non-goals

ProjectManager does not replace ImprovementCore.
ProjectManager does not solve domain questions merely because they are inside projects.
ProjectManager does not treat a polished artifact as project completion.
ProjectManager does not make recovered evidence authoritative by itself.
ProjectManager does not equate 21 native project coordinates with 36 coverage cells.
