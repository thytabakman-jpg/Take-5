## Target

Research and build the nonproduction Take-5 foundation now so it can be tested. Do not transfer production authority, canonical ownership, or Reaserch state into Take-5 yet.

## Adaptive tool rule

Use the demonstrated C01-C48 repertoire and boundary controls adaptively. After every material tool result, reconstruct the frontier and select the next highest-information licensed action. Do not run tools ceremonially.

Every C01-C48 capability receives one disposition: EXECUTED_DIRECT, EXECUTED_SUPPORT, SUBSUMED_WITH_WITNESS, NOT_APPLICABLE_WITH_REASON, BLOCKED, or OPEN. Nothing silently disappears.

## Workstreams

W1 CORE and KERNEL PD
Attack the two distinct objects using recursive discovery, orthogonal representations, factorization, hostile review, ablation, RTC, and holdouts.

W2 Full functionality recovery
Build a preservation ledger spanning Reaserch, Take-2, Take-3, Take-4, IC/ICC, PD, backend/runtime, map/capture, Project Anatomy, PracticalCore, TransferCore, validation, zero-request, and old organization/repair behavior.

W3 Foundation synthesis
Derive the foundation from recovered behavior, not historical package boundaries. Reclassify components across system-core, kernel, epistemic, controller, state, interface, runtime, verification, authority gate, capability, and OPEN/set-valued placement.

W4 External research
Compare by function with established work on OS kernels, control systems, agent architectures, planning/tool use, memory/state, orchestration, verification, fault tolerance, and related architectures. Feed discoveries back into W1-W3.

W5 Runnable build
Implement experimental Take-5 with task/goal/corpus intake, zero-request intake, frozen target, persistent typed state, capability registry/router, controller/reentry loop, semantic-worker adapter boundary, verification receipts, map capture, execution ledger, typed terminal states, and experimental outputs.

W6 Dump test
Provide one dump directory/manifest entry point. Corpus may arrive with an explicit job or no substantive job. Runner ingests, constructs a work frontier where licensed, executes available capabilities, persists state/results/receipts, and reenters until terminal under the experimental basis.

W7 Validation
Run historical matched fixtures, messy-folder organization/repair, zero-request treatment, ablations, order/interaction tests, regressions, and frozen unfamiliar holdout.

W8 Readiness packet
After W1-W7 meet the evidence threshold, produce a readiness packet and STOP. User launches a separate all-tools readiness attack before any migration.

## Immediate loop

Recover functionality -> PD Core/Kernel -> external compare -> revise architecture -> implement runnable dump system -> run fixtures -> verify -> reassess -> repair -> broaden validation -> readiness packet.

## Completion

Pre-migration build is complete only when every C01-C48 capability and every historically demonstrated protected behavior has an explicit disposition, Core/Kernel are implementation-stable under the declared evidence basis, runnable dump tests execute, blocking OPENs are closed or typed, and no migration has occurred.
